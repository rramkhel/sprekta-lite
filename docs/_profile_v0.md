## Planning Assistant Insights

### What Helps This User
1. **Time-blocked schedules** with specific start/end times
2. **Visual hierarchy** and clear sections (checkboxes, emojis, formatting)
3. **Critical items highlighted** (receipts, deadlines, budget checks)
4. **Context separation** (home vs. office tasks clearly delineated)
5. **Flexibility noted** (bus options, backup tasks)
6. **Reminders embedded** in relevant sections (not just listed separately)

### What to Remember for Next Time
- Always ask about **business hours constraints** for calls
- Clarify **location preferences** for different task types
- Check for **dependencies** (receipts needed for calls, budget checks before commitments)
- Consider **timezone differences** for stakeholders (Lilian in Eastern)
- Account for **commute variability** when scheduling
- Note **multi-day planning needs** (packing for 3 days)
- Remember this user works **day job + startup** simultaneously
- **Flag optimistic route planning** - gently reality-check cross-city errand timing
- **Remind about car logistics** - gas, returning borrowed car
- **"Get extra" items** - embed these reminders prominently (food for Friday, etc)
- **Early morning plans** - remind to set alarm
- **On-call windows** - build in flexibility for uncertain commitments (Real Roots)

### Red Flags to Watch For
- Tasks scheduled during transit time
- Calls scheduled during meetings
- No time allocated for meals
- Too many small tasks without consolidation
- Priority work (Sprekta) getting squeezed out by urgent tasks
- Overly optimistic route planning (cross-city errands in short windows)
- Forgetting to account for gas when borrowing mom's car
- Missing "get extra" reminders when buying multiples
