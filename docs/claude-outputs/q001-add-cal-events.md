> how do i add an event to the calendar? either manually or with ai?

⏺ Great question! Here's how to add events:

  Method 1: Quick Capture (AI-powered)

  1. Click the "Quick Capture" button (bottom-right orange button)
  2. Type naturally in the text box, like:
    - "Meeting with Sarah tomorrow at 2pm"
    - "Dentist appointment Friday at 10am"
    - "Call mom on Tuesday at 6:30pm"
  3. Click "Add"
  4. The event appears on the calendar

  Toggle Demo/Live Mode

  - Click the "DEV" badge (top-right) to open the dev panel
  - Toggle "Demo Mode" switch:
    - ON = Uses mock AI (no API key needed, instant responses)
    - OFF = Uses real Claude API (requires ANTHROPIC_API_KEY in .env)

  Method 2: Test Scenarios (Demo Mode Only)

  1. Click "DEV" badge → open dev panel
  2. Turn ON "Demo Mode"
  3. In "Test Scenarios" dropdown, select a scenario like:
    - "Event: Tomorrow with time"
    - "Event: Specific date with attendees"
  4. Click "Load into Quick Capture"
  5. Click "Add" in the quick capture modal
